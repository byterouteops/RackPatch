# Adoption metrics (legitimate only)

Track only what you can observe without invasive telemetry:

| Metric | Source |
|--------|--------|
| Template deployments | Railway dashboard (after publish) |
| GitHub stars / issues | GitHub |
| Support / Template Queue | Railway |
| Kickback earnings | Railway Earnings (after eligibility) |
| User interviews | Manual notes |

**Do not** equate stars with active users or invent retention rates. No product analytics pipeline in v0.1.
