# FINAL KICKBACK ELIGIBILITY GUIDE

**Date:** 2026-11-21  
**Source:** https://docs.railway.com/templates/kickbacks (verified same day)

## Eligibility

- Template **published** to Marketplace — **met** (`rackpatch`)
- Abide by Fair Use / ToS — maintainer responsibility
- **No Railway Hobby requirement** documented for kickback eligibility itself

## Rates (verify periodically)

- Base **15%** of usage cost of template services
- Support bonus **+10%** (25% total) via Template Queue activity
- Default payout → Railway Credits; cash via Earnings / Stripe Connect where country supported

## What does *not* earn kickbacks

- Your own publisher smoke project usage
- Artificial / abusive load
- Unpublished templates

## Manual actions (user)

- Review Railway **Earnings** tab when deployments appear
- Answer Template Queue questions for support bonus
- Stripe Connect only if cash withdrawal desired (do not automate)
