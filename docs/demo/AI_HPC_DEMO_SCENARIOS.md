# AI/HPC Demo — Scenarios

> **DEMO / SYNTHETIC DATA.** Northstar Infrastructure Labs, Northstar DC1 and every device, user, address and IP below are fictional. Generated by `scripts/gen-ai-hpc-docs.ts` from `src/lib/demo/ai-hpc/*`; do not edit by hand.

20 guided scenarios. The same list drives the in-app **Start demo tour** button. Routes are relative to the demo project. Users sign in as `<key>@demo.northstar.local`.

## 1. Executive commissioning overview

- **Route:** `(overview)`
- **Sign in as:** `owner`
- **Show:** KPI strip: matched, swapped, mismatch, awaiting, installed, blocked; Handover gate: critical exceptions and signed stages; Every figure links to its records
- **Expected:** KPIs equal the counts on the Cables and Exceptions pages.

## 2. Fabric overview (FE / BE / OOB / EXT)

- **Route:** `/fabric`
- **Sign in as:** `lead`
- **Show:** Per-fabric planned/installed/verified (also on the overview 'Fabric readiness'); Design attributes labelled 'design'
- **Expected:** Per-fabric totals add up to the cable total.
- **Limitation:** EVPN, RoCEv2, PFC/ECN are design metadata only; LLDP does not verify them.

## 3. Rack elevations

- **Route:** `/racks`
- **Sign in as:** `lead`
- **Show:** 14 racks, devices by rack unit; Status colour per device
- **Expected:** Device U positions never overlap; all fit in 42U.

## 4. GPU rack front/rear

- **Route:** `/racks/R08`
- **Sign in as:** `tech`
- **Show:** 8U GPU servers; FE 100G, BE 400G rail-aligned, BMC ports
- **Expected:** Each GPU has 2 FE, 4 BE and 1 BMC cable.

## 5. Fabric topology

- **Route:** `/fabric`
- **Sign in as:** `engineer`
- **Show:** FE spine/leaf + border; BE spine/leaf rails A/B
- **Expected:** No cable connects FE switching to BE switching.

## 6. Back-end rail view

- **Sign in as:** `engineer`
- **Show:** NIC k → BE-LEAF-0(k+1); 800G spine uplinks
- **Expected:** Rail A = BE-LEAF-01/02, rail B = BE-LEAF-03/04.

## 7. Cable plan import + validation

- **Route:** `/plan`
- **Sign in as:** `lead`

## 8. Cable list by fabric

- **Expected:** Filters match fabric counts on the overview.

## 9. Work orders and field progress

- **Route:** `/work-orders`
- **Sign in as:** `tech`
- **Show:** Done FE/BE, in-progress OOB, blocked trunks
- **Expected:** Blocked cables carry a reason.

## 10. Mobile field workflow

- **Route:** `/scan`
- **Sign in as:** `tech`
- **Show:** Scan QR, update status, photo
- **Expected:** Works offline and syncs later.
- **Limitation:** Responsive web app with offline capability, not a native app.

## 11. Evidence explorer (multi-vendor)

- **Route:** `/evidence/explorer`
- **Sign in as:** `engineer`
- **Show:** NX-OS, EOS, Cumulus, Junos, IOS-XE, Linux lldpd; Raw CLI → parsed → expected vs observed
- **Expected:** Every capture is labelled SYNTHETIC with its snapshot.
- **Limitation:** Synthetic playback, not a live SSH collection.

## 12. Swapped cables (FE and BE)

- **Route:** `/exceptions`
- **Sign in as:** `engineer`
- **Show:** FE swap names its partner; BE NIC swap = right device, wrong port
- **Expected:** Both swaps appear with a fix playbook.

## 13. Wrong device / wrong port / missing neighbor

- **Route:** `/verify?result=mismatch`
- **Sign in as:** `engineer`
- **Show:** Unplanned spare host; Free leaf port; Uplink up but no LLDP
- **Expected:** Each has a distinct finding type and next action.

## 14. Unobservable and unsupported links

- **Route:** `/verify`
- **Sign in as:** `engineer`
- **Show:** Firewall HA, console server, panels, demarcs
- **Expected:** Never marked LLDP-verified; physical check required.

## 15. Stale and parser-error evidence

- **Route:** `/compliance`
- **Sign in as:** `lead`
- **Show:** RTR-02 capture older than policy; OOB-SW2 capture failed to parse
- **Expected:** Stale → Needs review; parser error affects only links no other side observes.

## 16. Exception assignment and due dates

- **Route:** `/exceptions`
- **Sign in as:** `lead`
- **Show:** Assign to contractor, set due date; Waiver requires reason
- **Expected:** Assignment and waiver are audited.

## 17. Independent physical QC

- **Route:** `/qc`
- **Sign in as:** `qc`
- **Show:** Confirm/reject each end; Installer cannot verify own work
- **Expected:** Rejection re-opens the cable as an exception.

## 18. Playback: fault → corrected

- **Route:** `/evidence/explorer`
- **Sign in as:** `lead`
- **Show:** Switch snapshot to CORRECTED; Exceptions auto-close with audit
- **Expected:** Corrected snapshot has no LLDP mismatches.

## 19. Staged handover approvals

- **Route:** `/handover`
- **Sign in as:** `owner`
- **Show:** Installation → QC → Engineering → Owner; Owner blocked while critical exceptions open
- **Expected:** Owner approval only after exceptions are closed or waived.

## 20. Read-only auditor

- **Route:** `/handover`
- **Sign in as:** `viewer`
- **Show:** Viewer sees everything; No mutation controls
- **Expected:** Every mutation is refused for the Viewer role.
