# Contributor roadmap

Good first areas (after public repo):

- Additional LLDP text fixtures / parser edge cases
- Docs and accessibility improvements
- CSV import validation messages
- UI polish within existing design tokens

Larger (post-v1.0 — Phases 9+):

- Arista / Juniper LLDP adapters
- Rack visualization
- Collection workers (security-sensitive)
- Continuous compliance snapshots

Do not implement new vendor integrations without tests and scoped PRs.
