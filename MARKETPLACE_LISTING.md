## Tagline

## Short description

Open-source data center cabling installation, verification, and handover platform.

## Long description

RackPatch helps data center deployment teams manage physical cabling projects from planning to handover.

Features:

- CSV cable plan imports
- Rack-level cable tracking
- Mobile-friendly installation workflows
- Multi-vendor neighbor evidence (Cisco NX-OS/IOS-XE LLDP, Cisco CDP, Arista EOS LLDP, Juniper Junos LLDP)
- Expected-versus-observed port comparison
- Swapped cable detection
- Independent physical verification
- Exception tracking
- Audit history
- Handover reports
- Team-based access controls

License: Apache 2.0 Community Edition. Optional assisted deployment services are separate from the software license.
