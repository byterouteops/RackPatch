# Customer onboarding guide

1. Deploy (Docker or Railway — see DOCKER_DEPLOYMENT_GUIDE / RAILWAY_DEPLOYMENT.md).
2. Sign in as first user; create workspace.
3. Create project (site name is a project field today — no separate Site entity).
4. Invite teammates (workspace team).
5. Import CSV plan; publish revision.
6. Install → LLDP → verify → handover.

Optional: request assisted pilot via homepage form ($299 service).
