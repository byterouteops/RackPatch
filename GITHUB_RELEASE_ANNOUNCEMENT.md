# GitHub release announcement — v0.1.0

**Published:** https://github.com/byterouteops/RackPatch/releases/tag/v0.1.0

RackPatch Community Edition — Apache License 2.0

Plan, install, verify, and hand over physical data center cabling with multi-vendor neighbor evidence and independent physical verification.

### Included

- CSV cable plans and revisions
- Install status tracking
- QR label print sheets
- Multi-vendor neighbor evidence (Cisco NX-OS/IOS-XE LLDP, Cisco CDP, Arista EOS LLDP, Juniper Junos LLDP)
- Expected-vs-observed comparison and swapped-cable detection
- Independent verification rules
- Handover snapshots
- First-run administrator setup (password + optional Resend magic link)
- Docker / Railway self-host docs

### Not included (yet)

NetBox sync, AI assistant, 3D twin, product analytics.
