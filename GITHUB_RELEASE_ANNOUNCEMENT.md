RackPatch Community Edition — Apache License 2.0

Plan, install, verify, and hand over physical data center cabling with NX-OS LLDP evidence and independent physical verification.

### Included

- CSV cable plans and revisions
- Install status tracking
- QR label print sheets
- Cisco NX-OS LLDP import and mismatch detection
- Independent verification rules
- Handover snapshots
- First-run administrator setup
- Docker / Railway self-host docs

### Not included (yet)

NetBox sync, AI assistant, multi-vendor LLDP beyond NX-OS, 3D twin, product analytics.
